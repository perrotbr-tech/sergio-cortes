# Sergio Cortés — tarjeta de presentación digital

Tarjeta estática de presentación digital publicada mediante GitHub Pages en https://perrotbr-tech.github.io/sergio-cortes/.

- `index.html`: estructura, contenido y enlaces de la tarjeta.
- `og.jpg`: imagen de vista previa al compartir el enlace. No debe renombrarse: WhatsApp utiliza ese nombre para la vista previa.
- `sergio-cortes.vcf`: contacto descargable para guardar en el teléfono.
- `.nojekyll`: permite publicar los archivos estáticos directamente en GitHub Pages.
- `.gitattributes`: conserva el formato binario del vCard y de la imagen en Git.
